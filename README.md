# 🛠️ Forge CLI

**Forge CLI** is a global .NET terminal tool designed to eliminate boilerplate when building **Clean Architecture Web APIs**. 

Instead of manually creating layers, folders, and repeated classes, Forge provides an interactive terminal UI to scaffold complete solutions and generate Domain Entities, EF Core Configurations, DTOs, and API Controllers instantly.

## ✨ Features

- **🚀 1-Click Solution Generation:** Instantly spin up a `.sln` with `Domain`, `Application`, `Infrastructure`, and `Api` layers pre-configured.
- **🧱 Smart Scaffolding:** Run the tool inside any existing solution to generate full vertical slices.
- **🎯 Precision Code Generation:** Automatically generates:
  - Domain Entities
  - EF Core `IEntityTypeConfiguration<T>`
  - Application DTOs (Records) & Service Interfaces
  - API Controllers with routing setup
- **🎨 Interactive UI:** Built on top of `Spectre.Console` for a smooth, keyboard-driven terminal experience.

## 📦 Installation

To install Forge CLI globally on your machine, clone this repository and run the following commands:

```bash
# Pack the tool into a NuGet package
dotnet pack

# Install globally from the local output directory
dotnet tool install --global --add-source ./nupkg ForgeCli
```

*(To update the tool later, run `dotnet pack` followed by `dotnet tool update -g --add-source ./nupkg ForgeCli`)*.

## 💻 Usage

Open your terminal anywhere and type:

```bash
forge
```

### Options

1. **Create New Web API Solution**
   - Run this in an empty directory.
   - Prompts for a solution name (e.g., `GymManagement`).
   - Generates the complete Clean Architecture folder structure using the custom `clean-api` dotnet template.

2. **Add New Entity (Scaffold)**
   - Run this in the root directory of an existing solution (where the `.sln` or `.slnx` file lives).
   - Prompts for the Entity name (e.g., `Subscription`).
   - Provides a multi-select menu to choose which layers/components to generate.
   - Automatically detects the solution name and applies the correct `namespace` to all generated files.

## 🏗️ Architecture Standard

Code generated by this tool strictly adheres to **Clean Architecture** principles. Dependencies flow inward toward the Domain layer, utilizing the Repository Pattern, Entity Framework Core configurations separate from entities, and ASP.NET Core Web API standards.
